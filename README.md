# Stroma

Stroma is a local-first interface for planning work with frontier AI models and executing it with lower-cost capable models.

## Development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run typecheck
npm run test
npm run build
```

The current implementation is a front-end product prototype. Provider connections and run data are intentionally simulated until backend credentials and account integrations are configured.
